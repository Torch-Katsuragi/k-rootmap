# K-MAPS

GISアプリケーション（Flutter製）

## 機能概要

### 🗺️ 地図・レイヤー機能
- **背景地図**: OpenStreetMapなど各種タイルソースに対応
- **オフライン地図**:
  - **GeoPackageキャッシュ**: タイルを単一ファイルで管理し、オフライン利用が可能
  - **一括ダウンロード**: 範囲・ズームレベルを指定した一括キャッシュ保存機能（進捗バー表示・並列ダウンロード）
  - **スマートフォールバック**: オフライン時はキャッシュ済みの上位ズームレベル（親タイル）を自動的に拡大表示し、地図の空白を防ぐ
  - **通信制御**: ネットワーク状態（圏外/機内モード）を検知し、無駄なリクエストを抑制
- **レイヤー管理**: 階層型レイヤー構造、表示/非表示切り替え、透過度設定
- **UI最適化**: マーカーやラインのサイズを最適化し、視認性を向上

### 📍 GPS・測量機能
- **リアルタイムGPS追跡**: 
  - 位置情報の連続取得
  - **ポイント都度保存方式**: GPS軌跡を安全にポイントとして保存
  - フォアグラウンドサービスによるバックグラウンド動作
  - 保存先PointLayerNodeを選択可能
  - レイヤー消失時の自動停止機能
  - 後でpoint→line変換により軌跡を復元
- **GNSS NMEA対応**: 高精度測位データ対応
- **GPS測量ツール**: ポイント・ライン・ポリゴン描画
- **GPS測量メタデータ**: 精度、時刻、データソース等を各ポイントに記録

### 📷 カメラ・画像機能
- **カメラ撮影**: アプリ内で写真撮影し、GPS座標と撮影時刻をEXIF情報として保存。地図上に自動的に表示。
- **画像管理**: EXIF情報の部分読み込みによる高速な画像表示

### 💾 データ管理・エクスポート
- **GeoPackage統合**: SQLiteベースの地理空間データベース（QGIS標準形式準拠）
- **属性テーブル**: 詳細なメタデータ管理
  - **Pointレイヤー専用機能**: 仮想`_coordinate`列で座標を直接編集可能
    - **座標系変換機能**: 15種類のEPSGコード（WGS84, JGD2011等）から選択可能
    - **検索・自動変換**: EPSGコードや地域名で検索し、WGS84へ自動変換して保存
- **インポート機能**: Shapefile, GeoJSON, KML, CSV, GPX（ドラッグ&ドロップ対応）
- **エクスポート機能**:
  - **レイヤー全体エクスポート**: 常に元の形状を保持（Polygon → Polygon、LineString → PolyLine）
  - **個別フィーチャエクスポート**: 属性テーブルから選択して出力
  - **対応形式**: Shapefile, GeoJSON, KML, CSV
  - **Point Cloud変換**: Polygon/Lineを構成点に分解して出力するオプション
  - **Shapefile完全対応**: .shp/.shx/.dbf/.prjファイル生成

## システム要件

- **Flutter**: 3.0以降
- **Dart**: 2.18以降
- **OS**: Windows 10/11、macOS 10.15以降、Ubuntu 18.04以降
- **メモリ**: 4GB以上推奨
- **ストレージ**: 500MB以上の空き容量
