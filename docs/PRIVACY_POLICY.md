# プライバシーポリシー (Privacy Policy)

**Root Maps**（以下、「本アプリ」）は、オープンソースソフトウェアとして提供されています。本アプリはユーザーのプライバシーを尊重し、取得した情報を適切に取り扱います。

## 1. 取得する情報と利用目的

本アプリは、以下の機能を提供するためにデバイスの権限と機能を利用しますが、**開発者・提供者がデータを収集・追跡することはありません**。すべてのデータはユーザーのデバイス内、またはユーザー自身が指定したクラウドストレージ（Google Drive等）にのみ保存されます。

### 1.1. カメラ (Camera)
- **利用目的**: 地図上に配置する写真マーカーの撮影、および共有フォルダ連携のためのQRコードの読み取りに使用します。
- **データについて**: 撮影された画像データはユーザーのデバイスのローカルストレージ、またはユーザーが設定した共有フォルダ（Google Drive等）にのみ保存されます。アプリ外に自動送信されることはありません。

### 1.2. 位置情報 (Location)
- **利用目的**: 現在地の地図上への表示、およびバックグラウンドでのGPS軌跡（トラッキング）の記録に使用します。
- **データについて**: 取得した位置情報の履歴データは、デバイス内の内部データベース（GeoPackage等）にのみ記録されます。

### 1.3. Bluetooth (周辺のデバイス)
- **利用目的**: 外部のBluetoothレーザー距離計（TruPulse等）と接続し、測量結果をアプリ内に取り込むために使用します。

### 1.4. Google Drive連携 (OAuth認証)
- **利用目的**: プロジェクトデータのバックアップや複数デバイス間での共有・同期のために、ユーザーの許可を得てGoogle Driveにアクセスします。
- **データについて**: OAuth認証によって得られたトークンはデバイス内に安全に保存され、設定したフォルダとのデータ同期にのみ使用されます。

## 2. 第三者への情報提供

本アプリ自体には、ユーザーの個人情報やトラッキングデータ（アクセス解析ツール等を含む）を第三者に提供・送信する機能は組み込まれていません。（※地図描画のために背景地図データを取得する際の通信を除きます）

## 3. 本ポリシーの変更

本アプリのアップデートに伴い、取得する権限や機能が追加・変更される場合、本ポリシーも改定されることがあります。改定されたポリシーは本ページにて公開された時点で有効となります。

## 4. お問い合わせ

本アプリはオープンソースプロジェクトです。ソースコードや不具合の報告、データ処理に関するご質問については、GitHubのIssueトラッカーを通じてご連絡ください。
