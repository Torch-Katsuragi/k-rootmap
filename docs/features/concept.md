# K-MAPS構想（Fresco風UI）

## コンセプト

「お絵描きアプリのような直感的な操作性で、誰でも気軽にGeoPackageデータを編集・作成できるモバイルアプリ K-MAPS」

## ターゲットユーザー

- フィールド調査を行う研究者・技術者
- GISの専門知識はないが、位置情報付きのメモやスケッチを作成したい一般ユーザー
- QFieldのような高機能GISアプリよりも、手軽さを求めるユーザー

## コアバリュー

- **直感的なUI/UX**: Adobe Frescoのようなツール切り替えやレイヤー操作で、学習コストを低くする。
- **手軽さ**: 専門知識がなくても、地図上にお絵描きする感覚で地理空間データを作成・編集できる。
- **モバイルファースト**: スマートフォンやタブレットでのGPS連携やタッチ操作に最適化する。
- **Googleエコシステム連携**: Google Driveへの保存・同期をスムーズに行う。
