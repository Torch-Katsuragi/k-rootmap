# レイヤー管理機能

Adobe Frescoのような直感的なレイヤーパネルを提供します。

## フォルダ構造とGeoPackageファイルに連動したレイヤー/レイヤーグループ

- プロジェクトフォルダ内のサブフォルダ構造が、K-MAPS内のレイヤーグループ階層としてそのまま反映される。
- 各フォルダ内に存在するGeoPackageファイル（.gpkg）は、そのフォルダに対応するレイヤーグループ内に「GeoPackageソース」のような特別なアイテムとして表示される。
- 「GeoPackageソース」アイテムを展開すると、そのGeoPackageファイル内に保存されている各レイヤーが一覧表示される。
- これにより、「フォルダグループ → （サブフォルダグループ / GeoPackageソース → GeoPackage内部レイヤー）」という階層構造を実現する。

## グローバルフォルダ

- プロジェクトに依存しない共有フォルダとして「グローバルフォルダ」を提供。
- アプリケーションのドキュメントディレクトリ（`getApplicationDocumentsDirectory()`）に実体が存在。
- どのプロジェクトを開いても、ルート直下のサブフォルダとして表示される。
- グローバルフォルダ内のGeoPackageや写真も通常と同様に地図上に表示・操作可能。
- 視覚的な区別のため、アイコンが青色で表示される。

## レイヤー操作

- レイヤー/レイヤーグループ/GeoPackageソースの追加、削除、複製、名称変更。
  - フォルダやGeoPackageファイルの操作は、実際のファイルシステム構造にも反映される（またはその逆）。
- レイヤーの表示/非表示切り替え（個々のレイヤー、GeoPackageソース全体、フォルダグループ全体）。
- レイヤー/レイヤーグループ/GeoPackageソースの順序変更（ドラッグ＆ドロップ）。
- レイヤーごとの透過度設定。
