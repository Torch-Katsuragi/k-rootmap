# K-MAPS v0.5.1 リリースノート (内部テスト用)

## 🚀 主な新機能・改善点

### 1. 描画パフォーマンスの劇的な向上 (MapLibre移行)
- 地図描画エンジンをFlutterMapからMapLibre GLに刷新しました。大量のポリゴンや数千件のポイントデータを開いても、アプリがサクサク動くようになりました！
- ポイントマーカーや写真アイコンのGPU描画化により、ズーム・パン時のカクつきが解消されています。
- ズームレベルに応じたポイントの自動クラスタリング（グループ化）に対応しました。

### 2. Google Drive連携の追加 (モバイル版)
- プロジェクトやデータをGoogle Driveと直接同期できるようになりました。
- 複数デバイス間でのデータ共有や、クラウドへのバックアップをスマートに行えます。

### 3. 高度な測量機能とレーザー距離計(TruPulse)連携
- TruPulse(Bluetoothレーザー距離計)と接続し、測定データを直接地図上に反映できるようになりました！
- 「ポイント」から「ライン・ポリゴン」への変換ダイアログを実装し、コンパス法則やトランシット法則による**閉合差補正**に本格対応しています。
- 磁気偏角、器械高、目標高の補正機能も利用可能です。

### 4. QGISライクな属性フィルタと抽出機能
- 属性テーブル内で「QGIS式（WHERE句）」を利用したフィルタリングが可能になりました。
- フィルタした結果だけを新しいレイヤに一括コピー抽出する機能で、GIS作業の効率がアップします。

### 5. GPS軌跡(トラッキング)の常時記録と抽出
- GPSのオン/オフを手動で管理する手間を廃止し、バックグラウンドでのGPS常時記録に移行しました。
- 地図上には「本日の軌跡」がリアルタイム表示されます。「軌跡抽出」ツールを使って、時間帯を指定してラインデータとして簡単に切り出すことができます。

### 6. その他
- 「グローバルフォルダ」機能を追加し、複数プロジェクトで共通の背景地図やデータを使い回せるようになりました。
- 詳細な設定画面の宣言的UI化、アプリ全体の安定性向上や不要な競合状態のバグを多数解消しています。
